Running AI models locally gives developers control, privacy, and better performance. With .NET, you can easily integrate AI into your apps without relying on the cloud. This post covers how to use AI models locally in .NET applications with Semantic Kernel.

1 — Install Ollama — https://ollama.com/

Follow directions to install.

2 — Download a model — https://ollama.com/library?sort=newest

You can compare models from: https://artificialanalysis.ai/models. For demo purposes, you can install a small model (such as: https://ollama.com/library/phi4-mini)

3 — Start Command Line/Terminal and run the command; it might take a while to download the model.

ollama run <model name>

Ex: ollama run phi4-mini

4 — Confirm ollama is running @ http://localhost:11434/

5 - Run the application
